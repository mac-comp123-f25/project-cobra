# Cobra Snake

This project aims to recreate the classic snake game. This game is made using python 3.13 and pygame 2.6.1.
To start the game, runs the "MainGame.py" file. 
Once the game starts, the user can select from three different level of difficulties, easy, medium, and hard. 
Easy mode features the basic game play. There is a snake, and the goal is to eat as many apples as possible.
The user can move the snake using arrow keys, and the snake will automatically eat apples once it collides with them.
Everytime the snake eats one apple, the snake will grow longer, and the score will be increased by 10.
The game will be over if the snake collides into the walls (boundaries), or the snake itself. 
If the user clicks the arrow key that has the exact opposite direction as the snake moves, 
it will be considered the snake has collided into itself. 
Medium mode features the same as the Easy mode, with obstacles appeared as gray squares. 
The game will be over if the snake collides into the obstacles. 
Hard model features the same as the medium mode, with the snake moves at a faster speed.
Once the game is over, the user can press "esc" to go back to the main menu and reselect the difficulty,
or the user can press "space bar" to retry that level.
The user can choose whether to play with music or not by clicking the music button in the top left corner.
The user can end the game by terminating the program or clicking the "X" in the top right corner.
