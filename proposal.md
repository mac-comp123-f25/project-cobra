## Description
Our project is an imitation of the classic **Snake Xenzia** game, inspired by the early 2000s mobile game that defined an era of simple yet addictive entertainment for us.  It is a significant game that marks our childhood.
The player controls a snake that moves across the screen, collecting food to grow longer while avoiding collisions with the walls or itself.  

In our reimagined version, the game will feature:  
- Randomly appearing food items  
- Snake movement controlled by user key inputs  
- Level-based progression where **difficulty and time limits increase**  
- This is not certain yet but having a special **“cobra puff” animation** when a level is successfully completed would be great  

This version aims to blend nostalgic charm with smooth gameplay and modern design.

## Inspirations Behind

We chose this project because we share a sense of **nostalgia for early mobile gaming**, particularly Snake Xenzia, which was both simple and universally loved.  We all grew up in different countries in different parts of the world yet we all share this game as a commonality amng us.

Recreating it allows us to:
- Relive that nostalgic experience,  
- Strengthen our understanding of **game logic, event handling, and animation**, and  
- Apply our programming and teamwork skills to build something both fun and functional.
